# AskMyDB

A Natural Language to SQL Assistant built using:

- Python
- Gemini API
- MySQL
- Jupyter Notebook

## Features

- Ask questions in plain English
- Converts questions to SQL automatically
- Executes SQL on MySQL database
- Returns business insights instantly

## Example Questions

- What is the overall churn rate?
- Which country has the highest churn rate?
- How many active members are there?

## Tech Stack

Python | Gemini API | MySQL | Jupyter Notebook
